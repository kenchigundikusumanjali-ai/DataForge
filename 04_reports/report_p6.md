## Q1. What is the dashboard’s main business message?

The dashboard shows student performance using attendance, assignment scores, lab scores and student count. It helps compare departments and identify performance trends.

## Q2. Which filter changes the story most strongly?

The Department filter changes the dashboard the most because it updates all visuals for the selected department.

I would improve the dashboard design, add more interactive charts and include additional KPIs for better insights.
