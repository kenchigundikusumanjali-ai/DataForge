# Practical 1 Report

## Q1. What is one row in this dataset representing?

One row represents the academic and performance details of one student.

## Q2. Which columns look numerical, categorical and date/time?

### Numerical Columns

* attendance_pct
* diary_entries
* tasks_completed
* assignment_score
* lab_score

### Categorical Columns

* student_id
* name
* department

### Date/Time Columns

* No date/time column is present in this dataset.

## Q3. What can go wrong if a team starts analysis without a data dictionary?

Without a data dictionary, team members may misunderstand the meaning of columns, use incorrect data types, perform wrong calculations, and produce inaccurate conclusions.
