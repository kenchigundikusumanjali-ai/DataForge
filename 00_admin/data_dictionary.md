# Data Dictionary

| Column Name      | Data Type   | Meaning                              |
| ---------------- | ----------- | ------------------------------------ |
| student_id       | Integer     | Unique ID of the student             |
| name             | Text        | Student name                         |
| department       | Categorical | Student department or branch         |
| attendance_pct   | Numeric     | Attendance percentage of the student |
| diary_entries    | Numeric     | Number of diary entries submitted    |
| tasks_completed  | Numeric     | Number of tasks completed            |
| assignment_score | Numeric     | Assignment marks/score               |
| lab_score        | Numeric     | Laboratory marks/score               |
